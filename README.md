# QQ 名片点赞

适用于 MaiBot，支持 NapCat 和 SnowLuma。可以用命令或自然语言给 QQ 用户名片点赞。

当前版本：1.0.1

## 安装

从插件商店安装，或将插件文件解压到 MaiBot 的插件目录。在 WebUI 中启用插件，填写管理员 QQ 后重启 MaiBot。

升级时先停止 MaiBot，备份插件数据，再替换文件。

## 使用

命令示例：

- `/赞 @张三`
- `/赞 @张三 5`
- 回复某人的消息后发送 `/赞`
- `/赞 123456789 5`
- `/点赞`、`/zan` 与 `/赞` 相同

也可以直接说“给我点个赞”“给 123456789 点 3 个赞”或“给我点满”。自然语言请求会直接执行，不需要再发送命令。

次数范围为 1 到单次上限。未指定次数时使用默认次数，“点满”使用单次上限。每日额度不足时按剩余额度发送。无效号码、多个目标或无法确认的指代不会执行，需要时请直接 @ 对方或回复对方的消息。

自然语言请求只能处理最近 3 分钟内、能够查到原文的消息。管理员限制、冷却和每日额度同样适用。

## 配置

配置可在 MaiBot WebUI 的插件设置中修改。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `plugin.enabled` | `true` | 启用或停用插件 |
| `plugin.config_version` | `1.0.1` | 配置版本，请勿手动修改 |
| `like.default_times` | `10` | 未指定次数时使用，范围 1 至 20 |
| `like.max_times` | `20` | 单次点赞上限，范围 1 至 20 |
| `like.daily_limit_per_target` | `30` | 每个目标每天的额度，范围 1 至 50 |
| `like.cooldown_seconds` | `30` | 同一发送者的冷却时间，设为 0 可关闭，最大 3600 秒 |
| `like.allow_at_target` | `true` | 允许通过 @ 指定目标 |
| `like.allow_reply_target` | `true` | 允许通过回复消息指定目标 |
| `like.allow_raw_qq` | `true` | 允许直接输入 QQ 号指定目标 |
| `like.enable_llm_tool` | `true` | 允许使用自然语言请求点赞 |
| `admin.admin_only` | `true` | 仅允许管理员使用 |
| `admin.admins` | 空 | 管理员 QQ 号，多个号码用逗号分隔 |

默认只允许管理员使用。开启管理员限制时要先填写 `admin.admins`，留空时不会执行点赞。关闭管理员限制后，所有用户仍受冷却和每日额度限制。

## 适配器

NapCat 和 SnowLuma 都可以使用。插件会检查点赞接口和登录信息接口；无法确认机器人 QQ 号时不会发送请求。请求超时或结果不明确时不会自动重试。

## 数据与升级

点赞记录保存在插件数据目录的 `like_ledger.sqlite3`。首次升级会从旧版 `like_state.json` 迁移数据，原文件会保留。升级前建议备份整个插件数据目录。

请求结果不明确时，额度会暂时保留。请先检查 MaiBot 和适配器日志，不要直接删除账本。

## 兼容范围

- MaiBot：1.2.0 至 1.3.99
- maibot-plugin-sdk：2.7.1 至 2.99.99，同时要满足 MaiBot 自身的 SDK 依赖
- NapCat 或 SnowLuma
