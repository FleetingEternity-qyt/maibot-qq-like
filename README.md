# QQ 名片点赞

MaiBot 的 QQ 名片点赞插件，支持命令、口语和每日定时点赞。适用于 NapCat、SnowLuma。

当前版本：1.0.2

## 安装

从插件商店安装，或解压到 MaiBot 插件目录，重启后在 WebUI 插件设置中填写管理员 QQ。

## 使用

- `/赞 @张三`：给张三点赞，也可以回复对方的消息发送 `/赞`。
- `/赞 123456789 5`：给指定 QQ 点 5 个赞。`/点赞`、`/zan` 也可以。
- 直接说“给我点个赞”“给我点满”也可以，不用再发命令。

默认点 10 次，“点满”按单次上限执行。默认只有管理员能使用，可在设置中关闭限制。

## 定时点赞

在 WebUI 插件设置中打开“定时点赞”，填写 QQ 名单、执行时间和每人点赞次数，保存即可。

名单如 `123456789, 987654321`，也可以用空格或换行分隔。时间如 `09:00`、`21:30`，按运行 MaiBot 的电脑时区计算，MaiBot 需要保持运行。

当天错过时间后启动会补执行，已提交的当天任务不会因重启重复发送。定时名单不受聊天管理员限制，与手动点赞共用每日额度。

## 配置

在 WebUI 中修改，保存后生效。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `plugin.enabled` | `true` | 插件总开关 |
| `plugin.config_version` | `1.0.2` | 配置版本，无需修改 |
| `like.default_times` | `10` | 默认次数，1～20，不超过单次上限 |
| `like.max_times` | `20` | 单次上限，1～20，所有点赞方式共用 |
| `like.daily_limit_per_target` | `30` | 每个 QQ 的每日额度，1～50，所有点赞方式共用 |
| `like.cooldown_seconds` | `30` | 聊天请求冷却秒数，0～3600，0 为关闭 |
| `like.allow_at_target` | `true` | 允许 @ 指定目标 |
| `like.allow_reply_target` | `true` | 允许回复指定目标 |
| `like.allow_raw_qq` | `true` | 允许 QQ 号或口语昵称指定目标 |
| `like.enable_llm_tool` | `true` | 允许口语点赞 |
| `admin.admin_only` | `true` | 聊天点赞仅限管理员 |
| `admin.admins` | 空 | 管理员 QQ，多个用逗号分隔 |
| `schedule.enabled` | `false` | 定时点赞开关 |
| `schedule.time` | `09:00` | 每天执行时间，24 小时制 |
| `schedule.qq_list` | 空 | 定时点赞 QQ 名单 |
| `schedule.times` | `10` | 每人每天点赞次数，1～20，受单次上限限制 |

额度不足时按剩余额度发送；请求超时或结果不明确时不会自动重发，也不会释放本次额度。

## 升级与兼容

升级前停止 MaiBot，备份插件数据目录后替换文件。旧版点赞记录会自动迁移，请保留数据目录中的账本文件。

支持 MaiBot 1.2.0～1.3.99、SDK 2.7.1～2.99.99。使用官方启动器时，SDK 按主程序的依赖要求安装。
